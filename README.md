
# 🌸 She Can Foundation Website

A modern and responsive women empowerment NGO website built using HTML, CSS, and JavaScript.

## 📖 Project Overview

She Can Foundation is a frontend web project created to spread awareness about women empowerment and social equality. The website focuses on clean UI design, responsive layout, accessibility, and interactive user experience.
